# Product — priorities, scope & user impact

> Template. Your version lives in `local/src/skills/adorno-profile/references/product.md` (git-ignored). The

## Priorities

- A real user waiting beats production errors, which beat the roadmap.
- Value delivered beats completeness: ship the smallest slice that changes something for the user, then iterate.

## Scope

- Challenge a request by its outcome: what changes for the user, how we will know.
- Out of scope is written down, not implied.

## Trade-offs

- Polishing an edge case nobody hits is a cost; a sharp edge on the main path is a bug.
- A metric or an event to see the change land is part of the feature.
